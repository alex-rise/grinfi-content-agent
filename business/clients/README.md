# Your businesses live here

One folder per business you write for: `business/clients/<name>/`.

Everything inside is ignored by git. It stays on your machine, it is never
pushed, and it never reaches anyone else's copy of this kit. That is deliberate:
a client's numbers, cases and voice are theirs.

Six files per business, created by the `onboarding` skill:

| File | What is in it |
| --- | --- |
| `profile.md` | who buys, how they buy, what proves it |
| `facts.md` | what may be asserted, with its source, and the red list |
| `voice.md` | their voice, taken off recordings |
| `channels.md` | platforms, languages, who approves, channel ids |
| `materials.md` | the catalogue of photos, recordings and screenshots |
| `what-works.md` | the numbers their posts actually got |

Plus `sources/` - one file per recording, holding where it came from, the cores
mined from it and the list of what must never be published.

If you work for several businesses, keep them in separate folders and never let
one business's facts into another's post. The check is mechanical: before a post
goes out, every number in it must appear in that client's own `facts.md`.
